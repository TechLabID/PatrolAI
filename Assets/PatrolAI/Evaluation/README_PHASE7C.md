# Phase 7C preregistered pilot methodology

This is a **pilot synthetic/local benchmark**, not statistically conclusive industrial validation. EXTERNAL LABEL REVIEW: PENDING. Labels, v2 rules, envelope and service prompt/schema must be frozen before inference and must not be tuned against outputs.

Ground truth: sufficient agreed safe evidence permits SAFE/CONTINUE; verified immediate personnel/electrical/thermal/pressure danger requires DANGER/STOP; weak, stale, missing, unclassified or unresolved contradictory evidence requires UNKNOWN/REOBSERVE while budget remains. A documented authorized reset and current same-target agreement can clear a prior hazard. Unresolved evidence after two attempts requires DANGER/STOP for human review. Proposed labels are authored internally, independently of predictions; a blank reviewer sheet supports external review without inventing approval.

V2 preserves v1 and adds sufficient-quality/current-evidence checks, conflict -> REOBSERVE, an explicit confirmed_hazard=true override for otherwise sufficient inputs, and bounded escalation. Quality precedence conservatively keeps unresolved evidence in REOBSERVE until its budget expires. Sufficient RED -> STOP; GREEN/NORMAL/AREA_CLEAR -> CONTINUE; unknown conditions -> REOBSERVE. No case ID or expected label is read by either rule engine.

All three predictions pass through the SAME deterministic safety envelope and production PatrolActionMapper. Allowed operational actions: CONTINUE, REOBSERVE, STOP. Malformed/unsupported/failed inference -> STOP for human review, truthfully attributed to the envelope. CONTINUE on unresolved evidence -> REOBSERVE. At the maximum attempts (default 2), unresolved evidence or a proposed REOBSERVE -> terminal STOP. Demo maximum is 1 to keep two inference calls. A pending REOBSERVE below budget is not a completed safe outcome. No automatic third model call or re-observation occurs.

Reports retain raw proposal and envelope-effective decision, exact/action correctness, unresolved status, escalation and override attribution. Primary comparative metrics use the common operational envelope. Raw proposed decision/action correctness is reported separately so deterministic intervention cannot be mistaken for model reasoning. Failed model calls never earn AI correctness even if operational fallback STOP agrees with a label; runtime failure remains counted. Rates use the same expected-action denominators as Phase 7B; unresolved cases are un-escalated effective REOBSERVE results, escalated cases are envelope/rule budget STOPs.

Exactly 16 new cases, one live inference each; no retries. A create-new run marker prevents full reruns. A pre-inference snapshot stores inputs, labels, and SHA-256 fingerprints of v1, v2, envelope, dataset, reasoning service and request schema. Temperature=0.1, max completion tokens=512, thinking disabled; no seed/top_p configured by this client. This is not a deterministic API guarantee. Repeated Phase 7B samples are repeatability observations, not independent rule samples: rules 6/12 unique cases, Nemotron 11/12, with 12/12 cases showing 3/3 action and decision agreement.
