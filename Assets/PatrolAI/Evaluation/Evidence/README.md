# Stored historical reproducibility evidence

These are byte-for-byte copies of stored historical evidence. No inference or benchmark rerun was performed to prepare them. No benchmark rerun is required and no live credentials are required: a fresh clone can verify stored results/hashes locally using Python's standard library:

~~~powershell
python Assets/PatrolAI/Evaluation/Evidence/verify_stored_evidence.py
~~~

The verifier only reads stored evidence and public source. It checks the original 24 stored case pairs against public labels/categories and the production mapper whitelist, including the Phase 7B historical counts (18/24 rule actions, 23/24 model actions, seven action-correct risk-label mismatches and one unnecessary model REOBSERVE). It also checks all nine original freeze fingerprints. It does not invoke a model, evaluation runner, rule engine, safety envelope, Unity, or network operation, or write replacement results. It does not verify the separate 36-call repeatability run or live API provenance.

## Gap and provenance

The existing Phase 7B offline harness reads evaluation/results/phase7_ai_necessity_results.json. That directory is ignored, so a fresh clone lacks its historical input even though the Git/Python/offline prerequisites pass. This public copy supplies the original stored input without synthesizing model decisions. The command above checks the relevant stored-result counts without generating files. The legacy harness still expects its original relative path; this verifier reads the public evidence path directly.

Original report timestamp: 2026-10-05T06:20:31.9783051Z; stored requestCount: 24. The report contains historical normalized decision pairs and model reasons, not the full raw HTTP response. Historical REAL markers are stored metadata, not a claim of a new live call.

Phase 7C's runner stores the snapshot and manifest before entering its inference loop. The manifest contains eight source/policy SHA-256 hashes and one frozen-case SHA-256 hash. It supports the published 9/9 MATCH integrity claim; it is not a model accuracy score, independent timestamped preregistration, or external chain-of-custody proof. The snapshot is internally authored synthetic/local sample evidence; external label review remains pending. Original full input/prompt freeze remains NOT VERIFIED.

No sanitization was necessary or performed. Copies retain all decisions, scores, labels and evidence hashes unchanged. A sanitized copy, if used in future, must not alter decisions/scores/labels/hashes; these copies are unsanitized. No historical hash was rewritten.

## Exact hash coverage

Every digest in frozen_source_hashes.txt is the original uppercase SHA-256 value; all are independently recomputable from public candidate files. The eight file entries cover their entire historical file bytes:

| Manifest entry | Covered content |
| --- | --- |
| Assets/PatrolAI/Evaluation/PatrolHeldOutDataset.cs | Held-out observation construction and proposed labels |
| Assets/PatrolAI/Evaluation/RuleBasedSafetyBaseline.cs | Rule v1 implementation |
| Assets/PatrolAI/Evaluation/RuleBasedSafetyBaselineV2.cs | Rule v2 implementation |
| Assets/PatrolAI/PhysicalAI/PatrolSafetyEnvelope.cs | Shared deterministic safety envelope |
| Assets/PatrolAI/NVIDIA/NebiusNemotronReasoningService.cs | Production service and system prompt |
| Assets/PatrolAI/Nebius/NebiusClient.Chat.cs | Client request/schema implementation |
| Assets/PatrolAI/PhysicalAI/PatrolActionMapper.cs | Production action whitelist |
| Assets/PatrolAI/Evaluation/README_PHASE7C.md | Historical pilot methodology |
| frozen_cases | UTF-8 bytes of the stored serialized 16-case input/label snapshot, preserved in frozen_cases.json |

The historical source files use LF. For a Git checkout, the verifier hashes public HEAD blobs and checks that working source matches apart from CRLF checkout conversion; this reproduces historical bytes even with automatic Windows line endings. In a source export without Git metadata it hashes the supplied source bytes directly, which must retain their historical LF bytes. The local attributes in this evidence directory disable line-ending conversion to preserve copied artifact bytes. README_PHASE7C.md is deliberately unchanged because it is part of the historical hash evidence.
